Hoe het werkt

1

Analyseer je repository

De tool scant je codebase en detecteert automatisch talen, frameworks, en belangrijke bestanden.

python main.py analyze /pad/naar/repo
2

Beschrijf je doel

Vertel wat je wilt bereiken. De tool stelt verduidelijkingsvragen voor optimale context.

python main.py prompt --goal "Fix de login bug"
3

Ontvang je prompt

Krijg een gestructureerde, effectieve prompt inclusief aanbevolen aanpak en vervolgstappen.

→ Gegenereerde prompt + tips + follow-ups

Installatie

1. Clone de repository

git clone https://github.com/your-repo/claude-code-helper.git cd claude-code-helper

2. Installeer dependencies

pip install -r requirements.txt

3. Start de tool

# Analyseer een repository python main.py analyze /pad/naar/repo # Genereer een prompt python main.py prompt --goal "Jouw doel hier" # Interactieve modus python main.py interactive

Commando's

analyze

prompt
